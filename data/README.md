# Data

This project uses **Next Steps (Longitudinal Study of Young People in England, LSYPE1)**, available through the UK Data Service (Study Number 5545).

The participant-level Next Steps data are not included in this repository. Access to the study data is available to registered UK Data Service users under the End User Licence.

The modelling dataset was constructed from the original study files using the staged notebooks in this repository.

Stage-specific derived data files are not included in the public repository. The shared materials are limited to code, documentation, and anonymised or pre-aggregated outputs used to report the analysis.

For questions about access to non-public derived outputs, please contact the author.
